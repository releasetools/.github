# Security policy

Report a vulnerability through the repository's private reporting form, on its
Advisories tab. Do not open a public issue.

A report needs a reproduction, or a trace from an attacker-reachable entry point
to the flaw. Scanner output that matches a version string is not a trace.

What counts as a vulnerability, what does not, and what happens next:
[security reports](https://github.com/releasetools/conventions/blob/main/guides/security-reports.md).

These repositories are maintained by one person, and there is no SLA.
