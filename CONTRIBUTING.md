# Contributing

These repositories follow the [releasetools conventions](https://github.com/releasetools/conventions/blob/main/README.md): how a
change declares its type, what that type does to the version, where its
changelog entry goes, and what its release note says.

How the repositories are run is written down too:

- [Pull requests](https://github.com/releasetools/conventions/blob/main/guides/pull-requests.md), shaping a change so it can be reviewed
- [Reviewing](https://github.com/releasetools/conventions/blob/main/guides/reviewing.md), giving and receiving review
- [Issues](https://github.com/releasetools/conventions/blob/main/guides/issues.md), filing, answering and closing
- [AI-assisted contributions](https://github.com/releasetools/conventions/blob/main/guides/ai-contributions.md), disclosure and who is responsible
- [Security reports](https://github.com/releasetools/conventions/blob/main/guides/security-reports.md), what counts as a vulnerability
- [Markdown](https://github.com/releasetools/conventions/blob/main/guides/docs-style.md), how the docs are written

A repository that carries its own `CONTRIBUTING.md` says how to build and
release that one. This file says nothing about either.
