# Contributing

These repositories follow the
[releasetools conventions](https://github.com/releasetools/conventions/blob/main/README.md): how a change
declares its type, what that type does to the version, where its changelog entry goes, and what its
release note says.

How the repositories are run is written down in the
[guides](https://github.com/releasetools/conventions/blob/main/guides/README.md), which is the index and
stays current as guides are added.

A repository that carries its own `CONTRIBUTING.md` says how to build and release that one. This file
says nothing about either.
