# Support

Questions go in the repository's Discussions where it has them, and otherwise
in an issue that says it is a question. Either way you get an answer; a
question filed as a bug is answered and closed rather than ignored.

The issue tracker is for bugs and for work somebody intends to do.

A vulnerability goes through private reporting instead, on the repository's
Advisories tab. See [SECURITY.md](SECURITY.md).

These repositories are maintained by one person, so an answer can take a few
days.
